# Companion is complete when the claim is reproducible

The public companion is done when four artifacts exist: completeness score on the QR/trace path, a recall rubric with labeled defective paths, an NK run plotting score against interdependency K, and a reproduction command plus CSVs. Real block hashes, PBFT, Fabric, EPCIS, and a consumer app are out of scope because they do not test integrity≠completeness and would delay submission.
